## Modes and filters

- **Modes:** LSB, USB, CW-L/U, AM, SAM, FM, DIGL/DIGU, DRM, SPEC — with per-mode filter preset memories.
- **Filter presets:** F1…F10 plus two variable slots per mode; adjustable low/high edges. Bandwidth is set deliberately — tap a preset chip, or type exact low/high cuts into the CUSTOM fields on the filter panel. The **Bandwidth Filter** panel (a floating card in the G2 layout, one per receiver) draws the passband but never changes it: the display is read-only, so a drag-tune over the passband — on the card or on the main panadapter — can no longer resize your filter by accident.
- **DDC sample rate:** the spectrum width control (48–1536 kHz) sets the receiver's DDC rate — wider sees more band, narrower spends the same bits on less spectrum (DSP tab → Bandwidth).
