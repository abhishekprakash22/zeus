## CW

- **Paddle / straight key in the G2's key jack:** element timing is done by the radio's **FPGA keyer** — zero latency, independent of the software. Settings → CW: keyer mode (Straight / Iambic A / B), speed (WPM), Farnsworth, sidetone pitch and level, dot/dash swap.
- **Paddle at the Pi (remote-head setups):** a paddle wired to Pi GPIO is also supported (DOT/DASH/PADDLE-ON GPIO assignments in the CW tab), using the classic VK6PH/N1GP/DL1YCF iambic engine.
- **CWX:** type-ahead keyboard CW from the CW console panel, with macros.
- **DeepCW:** the **CW⌁** key decodes CW on-screen (neural decoder); **SKIM** lanes decode several signals across the band at once — tap a lane to tune it.
