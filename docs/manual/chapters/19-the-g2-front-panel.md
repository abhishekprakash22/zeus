## The G2 front panel (knobs, buttons, LEDs)

Enable **Front Panel** in Settings → RADIO and the physical controls work — both when ANAN Core talks to the panel directly and when you're connected through the radio's p2app row (panel events are relayed automatically; the settings card shows which path is live).

- **Remapping:** the *Button & encoder mapping* grid on the same card reassigns any button or encoder. **Press a control on the physical panel and its row flashes** (press-to-identify) — this also surfaces buttons the shipped map doesn't know, which then appear with an *assign* picker. That is how you bind the panel's **PS** button: press it, watch the detected row appear, assign **TogglePureSignal**. PureSignal is never armed by any default — only a mapping you create can reach it. **MOX** and **TUNE** are pinned and cannot be remapped (a transmitter key stays where the legend says it is), and the main VFO knob is always the VFO. *Reset all* returns the shipped defaults; changes take effect on the very next press, no restart.
- **VFO encoder divide:** *Auto* derives the dial divisor from the selected tuning step and keeps the panel's acceleration curve, so a fast spin cruises across the band. A fixed value works like piHPSDR's VFO divisor — that many ticks per step, mechanically linear, acceleration bypassed — for a detent-feel dial that never runs away.
- **Live everywhere:** the on-screen VFO numerals follow the knob live (streamed, not polled) on every connected client at once — and so does every other panel-driven value: AF, AGC (RX2's AGC encoder drives RX2's AGC-T and flashes on the RX2 pane), drive, filter edges, attenuation, RIT.
- **Multifunction encoder:** the Thetis/piHPSDR model. **Press** the MULTI encoder once and the knob *chooses* the function — the top-right badge grows and goes solid accent, and each detent steps through the list (it wraps in both directions). **Press again** and the knob *operates* the chosen function. Five seconds of idling in select mode drops back to operate on its own. The badge lives top-right of the main screen at all times, flashing whenever the assignment changes, so the knob is never a mystery.
